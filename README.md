# Выбор технологии UI: Web Components и фронтенд-фреймворки

Статический ресурс для размещения на GitHub Pages.

## Что внутри

- `index.html` — основная страница;
- `styles.css` — оформление;
- `script.js` — интерактивный выбор сценария проекта.

## Как разместить на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите в корень репозитория файлы `index.html`, `styles.css`, `script.js`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - Source: `Deploy from a branch`;
   - Branch: `main`;
   - Folder: `/root`.
5. Сохраните настройки.
6. После публикации GitHub покажет адрес страницы.

## Смысл страницы

Страница превращает рекомендации из сравнительного анализа Web Components и современных фронтенд-фреймворков в компактный практический инструмент выбора технологии.
